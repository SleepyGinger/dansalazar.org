Privacy policy

Last updated 21 September 2026.

This policy covers home-mcp, a personal tool used by Dan Salazar to read and control his own Google Home and Nest devices. It has one user. It is not offered to the public.

What it accesses

With the permission home.platform.v2, granted by the account owner at sign-in, home-mcp can read the list of homes and devices on that Google account, read the current state of those devices, send commands to them, and read their recent history.

Typical data includes device names, room names, temperature and humidity readings, on/off and lock states, and the times those states changed.

What it stores

It stores the sign-in token Google issues, so it does not have to ask again on every use. That token is held privately by the account owner and is not published or shared.

Device readings are used to answer the owner's questions at the time they are asked. Some readings are kept in a private log on the owner's own machine, so that history can be reviewed later.

What it does not do

  • It does not sell data, and it does not serve advertising.
  • It does not share data with any third party beyond Google, whose API supplies it.
  • It does not transfer data to any other person.
  • It has no other users, so there is no other person's data to hold.

Removing access

The account owner can withdraw the permission at any time from the Google Account permissions page at myaccount.google.com/permissions. Withdrawing it stops all further access immediately. Stored tokens can be deleted at the same time.

Limited use

home-mcp's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
