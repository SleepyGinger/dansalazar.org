home-mcp

home-mcp is a personal tool. It lets Dan Salazar read and control his own Google Home and Nest devices from an AI assistant, using Google's Home API.

It is not a product, not a service, and not offered to anyone else. One person uses it, in one house.

What it does

Through Google's Home MCP server it can list the homes and devices on the account, read the current state of those devices, send commands to them, and read their recent history. In practice that means questions like "what is the thermostat reading?" and instructions like "set the heat to 68."

What it connects to

It talks to Google's own Home API at home.googleapis.com. It requests a single permission, home.platform.v2, which covers reading and controlling the devices already attached to the Google account that signs in.

Who it is for

The account owner, and nobody else. There is no sign-up, no other user, and no shared instance.
