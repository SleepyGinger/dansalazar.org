    Connect Google Maps

    The map needs a Google Maps API key. You set it up once. Google asks for a billing account, but personal use like this stays inside Google's free monthly allowance.

    1. In Google Cloud, create a project (or pick one) and create an API key.
    2. Turn on Maps JavaScript API and Places API (New).
    3. Restrict the key to websites, and add http://127.0.0.1:8787/*.
    4. In Terminal, run coffee-map key and paste the key. It is saved on this Mac only.
    5. Reload this page.
